# Yinova 群聊/转发用 — 中文

---

Yinova 六十四卦控制台，一键安装、开箱即用。

**环境**：macOS / Linux，Node.js 18+、npm

**安装（复制下面整段到终端执行，国内可用 Gitee）：**

GitHub：
```
git clone https://github.com/goldct/yinova && cd yinova
chmod +x install.sh start-panel.sh
./install.sh
```

Gitee（国内）：
```
git clone https://gitee.com/goldct/yinova && cd yinova
chmod +x install.sh start-panel.sh
./install.sh
```

**启动（复制下面一行）：**

```
./start-panel.sh
```

浏览器打开 http://localhost:3999 ，首次会进配置页，选厂商、填 API Key 保存即可。Mac 也可双击 `start-panel.command` 启动。
