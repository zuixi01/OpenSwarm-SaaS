# OpenSwarm 使用手册

## 一、快速开始

### 1. 安装与启动

```bash
git clone https://github.com/goldct/openswarm && cd openswarm
chmod +x install.sh start-panel.sh
./install.sh
./start-panel.sh
```

浏览器访问 http://localhost:3999。

**首次使用**：自动跳转配置页 → 选择模型提供商（如智谱）→ 填写 API Key → 保存。

### 2. 主面板概览

- **阴（太极白点）**：平台总控，点击启动/停止，会弹出终端运行 TUI。
- **阳（太极黑点）**：仅作展示，敬请期待 2.0 版本。
- **六十四员工**：每员工可单独启动、停止，点击「启动」会弹出该员工的终端 TUI。

## 二、阴与员工

### 阴

- 阴是平台总控网关，端口 18789。
- 点击阴眼「启动」→ 弹出终端，运行 `start-yin.sh`（网关 + TUI）。
- 若该员工/阴的终端已打开，再次点击会**复用已有窗口**，不再重复开窗。
- 与阴对话：在「项目空间」或「项目详情」中的「与阴对话」区域输入消息。**此处对话与终端 TUI 独立**，面板聊天记录与终端 TUI 的 session 不同步。

### 员工

- 每员工对应一个 openclaw 实例，端口 18791 起。
- 点击员工卡片的「启动」→ 若网关未起会自动拉起，再弹出该员工的 TUI 终端。
- 重复点击同一员工的「启动」→ 若终端已存在，会激活该窗口，不重复开窗。
- 员工的产出文件建议写在 `workspace/output/{projectId}/`，并在回复中写明完整路径。

## 三、项目与对话

### 项目空间

- 新建项目 → 选员工 → 进入项目详情。
- 项目内可「与阴对话」「与员工对话」。
- 与阴对话：仅属于当前项目，与终端 TUI 独立。
- 与员工对话：支持群聊（讨论模式）和单聊，可 @员工名 指定员工参与。

### 产出路径

- 员工产出文件时，请写入 `workspace/output/{projectId}/` 目录。
- 在回复中写明完整路径，如：`workspace/output/xxx/需求文档.md`。

## 四、常见错误与排查

| 错误提示 | 可能原因 | 排查建议 |
|----------|----------|----------|
| 阴网关未启动 | 未点击「阴·启动」或网关进程退出 | 点击阴眼「启动」，查看终端日志 |
| 智谱 API 限流(429) | 请求过于频繁或配额不足 | 稍后重试，检查 API Key 配额 |
| API Key 无效或配额不足 | 配置错误或额度用尽 | 到配置页面检查并更新 API Key |
| 阴网关返回了网页而非 JSON | chatCompletions 未启用 | 确认 `yin/moltbot.json` 中 `gateway.http.endpoints.chatCompletions.enabled = true`，重启阴 |
| 连接被拒绝（员工） | 该员工 Gateway 未启动 | 对该员工点击「启动」，确认 moltbot.json 中 chatCompletions 已启用 |
| 敬请期待2.0版本 | 点击了阳眼 | 阳眼当前仅作展示，功能将在 2.0 提供 |

## 五、配置与端口

- **面板**：默认 3999，可在配置页修改。
- **阴主网关**：18789。
- **员工**：18791 起，每员工一个端口。
- 配置页「检测端口占用」可自动查找空闲端口并更新配置。

## 六、一键操作

- **一键关闭所有终端**：关闭由面板打开的所有员工/阴终端窗口，不停止网关进程。
- **一键启动前 10 员工**：批量启动。

## 七、阳 · 技能组装

- 点击太极**阳眼**进入技能配置页。
- 选择项目，为每个员工勾选需要的技能（如 Summarize、GitHub、Wacli 等），保存。
- 员工执行任务时，系统会自动挂载所选技能到该员工的 workspace，员工即可使用。

详见 [技能来源](SKILL_SOURCES.zh.md)。
