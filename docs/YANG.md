# 阳 · 配置说明

阳负责为员工配置技能、定时、触发等，支持**手动勾选**和**自动配置**两种方式。

## 一、入口

- 面板首页 → 点击「阳」卡片，或
- 项目页「阴 · 控制台」→ 员工·技能区块 → 点击「阳配置」

## 二、手动配置

1. 选择项目
2. 在员工行中勾选需要的技能（如 Summarize、GitHub、Filesystem 等）
3. 点击「保存配置」

技能来源：ClawHub（`skills/skills.json`）。

## 三、自动配置（阳 · 自动配置）

1. 选择项目
2. 可选：在输入框补充描述（如「直播运营需内容策划、数据监控」）
3. 点击「阳 · 自动配置」
4. 阳会调用阴的 LLM 推理，自动为各员工分配合适的技能、定时、触发等
5. 推理完成后自动应用并刷新界面

### 前置条件

- **阴网关必须已启动**。若未启动，页面会显示红色提示条，且点击自动配置会返回「阴网关未启动」错误
- 启动方式：面板首页 → 点击「阴 · 启动」

## 四、阴未启动时的提示

当阴网关未启动时：

- 阳页面顶部会显示红色提示条：「阴网关未启动。使用「阳·自动配置」前请先在面板首页点击「阴·启动」。」
- 点击「阳·自动配置」会收到 503 错误及「请先启动阴」的提示
