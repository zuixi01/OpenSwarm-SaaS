# 阴 · 控制台使用说明

阴控制台位于**项目页**（`/project.html?id=xxx`）的「阴 · 控制台」区块，用于查看和配置当前项目的阴相关能力。

## 一、入口

1. 打开项目列表（`projects.html`）
2. 点击进入某个项目
3. 在项目页向下滚动，找到「阴 · 控制台」卡片

## 二、功能区块

### 2.1 配置

- **作用**：项目级键值对配置（env、密钥占位等），可注入到员工执行时使用
- **操作**：点击「编辑」→ 添加/修改/删除 key-value → 保存
- **示例**：`API_KEY=***`、`ENV=production`

### 2.2 员工 · 技能

- **作用**：展示本项目各员工已配置的技能
- **操作**：点击「阳配置」跳转到阳页面，可手动勾选或使用「阳·自动配置」

### 2.3 定时

- **作用**：按 cron 表达式定时触发员工执行
- **操作**：点击「+ 新增」→ 选择员工、cron、执行指令 → 保存
- **预设**：每日 9:00、每小时、每 15 分钟等

### 2.4 触发

- **作用**：Webhook 触发，外部系统可调用 URL 触发员工执行
- **操作**：点击「+ 新增」→ 配置 webhook → 复制 URL 供外部调用

### 2.5 流程

- **作用**：任务链 A→B→C，员工按顺序执行
- **操作**：点击「+ 新增」→ 添加步骤、指定下一员工 → 保存

### 2.6 API

- **作用**：对外 API 大门，支持 token 鉴权
- **操作**：点击「生成 Token」→ 在请求头携带 `Authorization: Bearer <token>` 调用

## 三、加载失败

若显示「加载失败」，请确认：

1. 面板已启动（`http://localhost:3999`）
2. 点击「重试」按钮重新加载
