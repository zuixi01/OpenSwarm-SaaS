# 项目页布局优化方案（project.html?id=p3）

## 一、当前布局概览

| 区域 | 内容 | 占比/说明 |
|------|------|-----------|
| **整页** | 项目名 + 主布局 | 无 max-width，全屏宽 |
| **左侧 main** | 与员工对话 + 与主控对话 | 80%（flex: 8），可拖动分割、全屏切换 |
| **右侧 aside** | 数字员工流程（选员工、启停、技能、分配任务）+ 主控控制台 | 20%（flex: 2） |

---

## 二、优化方向建议

### 1. 左右比例与响应式

- **现状**：左 80% / 右 20%，右侧栏较窄，员工卡片已做单列紧凑适配。
- **建议**：
  - 增加一个「窄 / 标准 / 宽」右侧栏宽度选项（例如 18%、20%、25%），或提供拖拽调整右侧宽度的 resizer。
  - 小屏（如 ≤900px）时改为上下布局：上为对话区，下为流程+控制台，避免右侧过窄导致阅读困难。

### 2. 左侧对话区

- **现状**：与员工对话、与主控对话左右 50/50，中间有 resizer 可拖。
- **建议**：
  - 默认比例可改为 55/45 或 60/40，突出「与员工对话」主流程。
  - 为两个对话区设置合理 `min-width`（如 280px），防止拖得过窄。
  - 固定/全屏时保留当前行为，仅优化默认比例与最小宽度。

### 3. 右侧「数字员工流程」结构

- **现状**：4 步（选择员工 → 员工技能 → 分配任务）+ 主控控制台（配置、定时、触发、流程、API）。
- **建议**：
  - 流程步骤可做成可折叠块（默认展开「选择员工」与「员工·启停」，其余折叠），减少首屏高度，需要时再展开。
  - 「主控·控制台」与「数字员工流程」之间增加明显分隔（如分割线或小标题），避免混在一起。
  - 若主控控制台使用率低，可收起到「主控控制台」一个入口，点击再展开或弹层，进一步减轻右侧纵向压力。

### 4. 顶部与导航

- **现状**：项目名、面包屑、返回、固定/全屏等在页面顶部。
- **建议**：
  - 项目名与面包屑同一行展示，节省纵向空间。
  - 固定、布局切换（三个点）等操作可收起到一个「视图」或「布局」下拉里，减少顶部按钮数量。

### 5. 聊天区域内部

- **现状**：模式选择、多轮、输入框、工具栏、消息列表。
- **建议**：
  - 工具栏（清空、更新记忆、产出文件、派发任务）可部分收起到「更多」或图标，避免一行过长。
  - 消息列表与输入框之间留足间距，并保证消息区有最小高度（如 240px），避免被挤压。

### 6. 视觉与层次

- **建议**：
  - 右侧流程卡片与主控控制台卡片统一圆角、边框、背景（与现有 control-bridge 风格一致），区分标题与内容层级。
  - 重要操作（选员工、一键启动/停止、技能编排）用同一套按钮样式，次要操作（如「生成 Token」）弱化。
  - 适当增加步骤编号与标题的字重/颜色对比，方便扫读。

## 三、实施优先级建议

| 优先级 | 项 | 预期效果 |
|--------|-----|----------|
| P1 | 右侧栏宽度可调或提供 18%/20%/25% 预设 | 适配不同屏幕与习惯 |
| P1 | 左侧两对话区默认 55/45 或 60/40 + min-width | 主次更清晰、防拖垮 |
| P2 | 右侧流程步骤可折叠 | 首屏更简洁 |
| P2 | 主控控制台与流程视觉分隔/折叠 | 减少右侧信息密度 |
| P3 | 顶部项目名+面包屑合并、操作收起到「视图」 | 节省纵向空间 |
| P3 | 聊天工具栏部分收起到「更多」 | 左侧更整洁 |

---

## 四、可落地的 CSS/结构改动摘要

1. **右侧宽度可调**：给 `.project-main-right` 加 `flex: 2` 的同时支持 `min-width`/`max-width`，或在外层包一层 resizer，用 JS 拖拽改变 flex-basis。
2. **左侧对话默认比例**：在 `.section-hex-chat` / `.section-yin-chat` 上设 `flex: 0 0 55%` 与 `flex: 0 0 45%`，并各设 `min-width: 280px`。
3. **右侧步骤折叠**：给每个 `.flow-step` 加折叠头（点击展开/收起），内容包在 `.flow-step-body` 里，用 `max-height` + `overflow: hidden` 或 `display: none` 控制。
4. **主控控制台分隔**：在 `.project-flow` 与 `.section-yin-dashboard` 之间加 `border-top` 或小标题「主控 · 控制台」，并可为该区块加折叠。
